# QA — проверка перед экспортом

| Проверка | Результат |
|---|---|
| Размер 1080 × 1920 px, PNG, RGB | 50 файлов |
| Безопасные зоны (текст в пределах y 250–1620, x 60–1020) | OK |
| Нет наложения текста на фото товара | OK |
| Шрифт Manrope загружен | OK |
| Один тип композиции не более двух раз подряд | OK |
| CTA в 5-й сторис каждого дня | OK |
| Выдуманные характеристики | нет — используются только тексты из ТЗ |
| Логотипы не искажены | оригиналов нет → текстовые названия; при добавлении SVG масштабируются пропорционально |
| Товар соответствует модели | **требует проверки после подстановки фото** |
