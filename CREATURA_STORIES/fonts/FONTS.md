# Fonts

The current minimal style (white studio, "MODEL by BRAND" lockup) uses **Manrope** only:

| File | Weight | Use |
|---|---|---|
| Manrope-Regular.ttf | 400 | Body copy, "by BRAND" |
| Manrope-Medium.ttf | 500 | Questions in closing stories, captions |
| Manrope-SemiBold.ttf | 600 | Model names, manufacturer wordmark, CTA, Creatura mark |

The Cormorant Garamond files (500 / 600 / 500 italic) are from the first editorial version of the brief. They are kept for optional use but none of the current layouts uses them.

Both families are from Google Fonts and licensed under the SIL Open Font License 1.1, so commercial use is free. All files include Cyrillic.
